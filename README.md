# База знаний АСИК

Обычные HTML-страницы. Ничего ставить не нужно.

## Как открыть

1. Скачайте/откройте папку проекта
2. Дважды кликните файл **`index.html`**

Готово — откроется в браузере (Chrome, Edge, Firefox).

## Что внутри

- `index.html` — каталог разделов
- `faq.html` — частые вопросы
- `articles/` — инструкции по модулям
- `css/`, `js/` — оформление и поиск
- `images/` — сюда кладите скриншоты (см. `images/README.md`)
