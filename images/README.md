# Скриншоты

Положите файлы рядом с этими папками, например:

- `start/step-1-1.jpg`
- `users-and-access/step-1-1.jpg`

Потом в статье замените серый блок «Вставьте скрин» на картинку:

```html
<figure class="shot" data-lightbox-trigger>
  <img src="../images/start/step-1-1.jpg" alt="описание">
</figure>
```

Путь к файлу уже написан на каждом плейсхолдере.
