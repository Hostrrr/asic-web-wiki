Начало работы

Цель

Базовые принципы работы в десктопном приложении АСИК — авторизация, интерфейс, навигация. Этот раздел — пререквизит для всех остальных модулей.

1

Авторизация пользователя

Запустите программу на рабочем столе. На кнопке входа должна быть ваша фамилия и инициалы. Если её нет — значит в системе 1С специалист не внесён как ответственное лицо. Для входа нажмите на кнопку с фамилией.

2

Выбор объекта

После успешной авторизации появится окно с объектами, в которых специалист принимает участие. Выберите нужный двойным кликом левой кнопки мыши.

3

Основные элементы интерфейса

  • Добавление — добавляет новый элемент в список или дерево, иконка «+»
  • Удаление — удаляет выбранный элемент, иконка «Корзина»
  • Редактирование — изменяет выбранный элемент, иконка «Карандаш»
  • Сохранение — нажимать каждый раз при завершении работы, чтобы сохранить результат
4

Боковая панель

  • Переход в личный кабинет
  • Переход на главный экран
  • Текущий этап заполнения информационной модели
  • Текущий шаг заполнения
5

Основы навигации

Переход к следующему этапу заполнения, вкладки окна заполнения, боковая панель.

6

Главное окно

В главном окне программы синим цветом обозначены модули, к которым специалисту разрешён доступ для получения информации и выполнения обязанностей. Для выбора другого объекта нажмите кнопку «Список объектов».

7

Список объектов

В окне списка объектов отображаются те, к которым есть доступ у специалиста. Выберите нужный, при необходимости воспользуйтесь полем поиска сверху.
