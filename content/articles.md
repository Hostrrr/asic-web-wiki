## slug: start
title: Начало работы
category: start
goal: Базовые принципы работы в десктопном приложении АСИК — авторизация, интерфейс, навигация. Этот раздел — пререквизит для всех остальных модулей.

### Шаг 1. Авторизация пользователя
Запустите программу на рабочем столе. На кнопке входа должна быть ваша фамилия и инициалы. Если её нет — значит в системе 1С специалист не внесён как ответственное лицо. Для входа нажмите на кнопку с фамилией.

[СКРИН: кнопка входа с фамилией пользователя]

### Шаг 2. Выбор объекта
После успешной авторизации появится окно с объектами, в которых специалист принимает участие. Выберите нужный двойным кликом левой кнопки мыши.

[СКРИН: окно списка объектов]

### Основные элементы интерфейса
- **Добавление** — добавляет новый элемент в список или дерево, иконка «+»
- **Удаление** — удаляет выбранный элемент, иконка «Корзина»
- **Редактирование** — изменяет выбранный элемент, иконка «Карандаш»
- **Сохранение** — нажимать каждый раз при завершении работы, чтобы сохранить результат

[СКРИН: иконка добавления «+»]
[СКРИН: иконка удаления «Корзина»]
[СКРИН: иконка редактирования «Карандаш»]
[СКРИН: иконка сохранения]

### Боковая панель
- Переход в личный кабинет
- Переход на главный экран
- Текущий этап заполнения информационной модели
- Текущий шаг заполнения

[СКРИН: боковая панель целиком]

### Основы навигации
Переход к следующему этапу заполнения, вкладки окна заполнения, боковая панель.

[СКРИН: элементы навигации по этапам]

### Шаг 3. Главное окно
В главном окне программы синим цветом обозначены модули, к которым специалисту разрешён доступ для получения информации и выполнения обязанностей. Для выбора другого объекта нажмите кнопку «Список объектов».

[СКРИН: главное окно с синими модулями]

### Шаг 4. Список объектов
В окне списка объектов отображаются те, к которым есть доступ у специалиста. Выберите нужный, при необходимости воспользуйтесь полем поиска сверху.

[СКРИН: окно списка объектов с поиском]

## slug: users-and-access
title: Пользователи и права доступа
category: module
goal: Ознакомление с функциональными возможностями модуля «Пользователи и права доступа» — добавление пользователей, создание ролей, назначение прав.

### Шаг 5. Первичное заполнение информационной модели
В главном окне программы слева доступен столбец «Первичное заполнение информационной модели». Заполнение производится последовательно по пунктам сверху вниз, начиная с пункта «Пользователи и права доступа».

[СКРИН: столбец первичного заполнения]

### Шаг 6. Пользователи и права доступа
В этом окне можно добавлять пользователей, которые будут работать над объектом, а также назначать им роли и права доступа к просмотру и редактированию данных. Заполнение начинается с создания ролей, которые потом присваиваются пользователям. Действие доступно только администраторам.

[СКРИН: экран пользователей и прав доступа]

### Шаг 7. Создание ролей
Для создания новой роли нажмите «+» в верхнем правом углу столбца. После создания роли становятся доступны кнопки редактирования и удаления. Для редактирования выберите роль из списка и нажмите иконку «Карандаш».

[СКРИН: список ролей с кнопкой «+»]

### Шаг 8. Распределение доступа
В этом окне распределяются права доступа для созданных ролей: доступ к версиям приложения, модулям, экранам и т.д. Это нужно, чтобы разные сотрудники видели только ту часть данных, которая нужна им для работы.

[СКРИН: экран распределения доступа]

### Шаг 9. Пользователи и права доступа
Здесь заполняются пользователи и присваиваются роли. Список пользователей подтягивается из базы 1С, ручное добавление не предусмотрено. Задача — дополнить информацию о пользователе полями справа и задать роль.

[СКРИН: карточка пользователя с полями]

### Шаг 10. Назначение на объект
Справа снизу — список объектов, на которые можно назначить пользователя. Чтобы назначить — отметьте чекбокс слева от названия объекта. Архивные объекты отмечены голубой иконкой, их показ можно отключить. После заполнения всех данных нажмите «Сохранить».

[СКРИН: список объектов с чекбоксами]

## slug: schemes-and-localization
title: Загрузка схем и локализация этапов строительства
category: module
goal: Ознакомление с функционалом модуля «Загрузка схем» — загрузка чертежей и построение структуры объекта по уровням.

### Шаг 5. Главный экран
После первичного заполнения информационной модели переходим ко вторичному. Первый пункт — виртуальное моделирование.

[СКРИН: главный экран, пункт виртуального моделирования]

### Шаг 6. Загрузка схем
Загрузите все имеющиеся схемы объекта, нажав кнопку «Загрузить схемы».

[СКРИН: кнопка «Загрузить схемы»]

### Шаг 7. Экран загрузки
На экране загрузки — 3 поля для схем согласно их названиям. Схему ПОС загружаем обязательно, она одна на весь объект. Схемы АР добавляем все в одно поле.

[СКРИН: экран загрузки с тремя полями]

### Шаг 8. Схемы загружены
После загрузки схемы отображаются на экране просмотра: можно просматривать, удалять и дополнять набор. Сохраняем и переходим во вкладку «Локализация структуры объекта».

[СКРИН: список загруженных схем]

### Шаг 9. Локализация структуры объекта
На этом экране загруженные схемы разбиваются на дерево с отдельными чертежами разных частей объекта.

[СКРИН: пустое дерево структуры объекта]

### Шаг 10. Создание структуры объекта
Структура незаполненного объекта выглядит пусто. Для заполнения создайте новый уровень кнопкой «+».

[СКРИН: кнопка «+» создания уровня]

### Шаг 11. Локализация структуры объекта
После создания нового уровня дайте ему название, например «Литер 1».

[СКРИН: ввод названия уровня]

### Шаг 12. Создание структуры объекта
Создаём следующий уровень 3-го порядка и называем его, например, «Блок-секция 1». Количество этих уровней равно количеству блок-секций объекта.

[СКРИН: уровень «Блок-секция 1»]

### Шаг 13. Локализация 4-го уровня
Создаём уровни 4-го порядка согласно имеющимся схемам: если есть схема этажа 1 для блок-секции 1, в уровне «Блок-секция 1» создаём подуровень «Этаж 1».

[СКРИН: уровень «Этаж 1»]

### Шаг 14. Привязка схем
Когда уровни 4-го порядка созданы, привязываем схемы: выберите пункт в дереве слева (например, «Этаж 1»), в столбце справа выберите соответствующую схему и отметьте чекбокс. Операция повторяется для всех пунктов и схем.

[СКРИН: привязка схемы к уровню дерева]

### Шаг 15. Локализация 5-го уровня
Создаём уровни 5-го порядка кнопкой «+». Главное отличие — в окне по центру становится активна кнопка «Шестиугольник», это режим разметки отдельных областей схемы.

[СКРИН: активная кнопка «Шестиугольник»]

### Шаг 16. Разметка
Размечаем нужную область, например «главный вход»: нажимаем «Шестиугольник» и ломаной линией левой кнопкой мыши обводим контур, правой — завершаем.

[СКРИН: процесс обводки контура]

### Шаг 17. Копирование структуры
Для быстрого копирования структуры выделите нужную область левой кнопкой мыши (например «БС1») и нажмите кнопку копирования.

[СКРИН: выделенная область и кнопка копирования]

### Шаг 18. Разметка
После завершения назначения чертежей — сохраняем.

[СКРИН: кнопка сохранения]

## slug: stropro
title: СтроПро
category: module
goal: Ознакомление с функционалом модуля СтроПро — назначение ТТК, распределение объёмов работ и бригад.

### Шаг 29. Вход в СтроПро
Войдите в модуль «СтроПро».

[СКРИН: вход в модуль СтроПро]

### Шаг 30. СтроПро
На этом экране выбираем ТТК для объекта, нужные материалы, объёмы работ и распределяем бригады.

[СКРИН: главный экран СтроПро]

### Шаг 31. Библиотека технологий строительства
Сверху справа — 3 вкладки: «Выбранные», «Библиотека», «Найденные». Чтобы назначить ТТК, перейдите на «Библиотеку» и отметьте нужные галочкой — они попадут во вкладку «Выбранные».

[СКРИН: вкладка «Библиотека» со списком ТТК]

### Шаг 32. СтроПро
Во вкладке «Выбранные» через иконку «Карандаш» или двойной клик по ТТК можно выбрать конкретные виды работ, например для ТТК «Разработка котлована» — один или несколько видов работ из меню справа.

[СКРИН: выбор видов работ по ТТК]

### Шаг 33. Распределение объёмов
На вкладке «Распределение объёмов» виден список ТТК, стрелка справа раскрывает виды работ. При выборе ТТК появляется таблица — объём работ вводится в столбце «Проект».

[СКРИН: таблица распределения объёмов]

### Шаг 34. Распределение бригад и подрядчиков
Слева — список субподрядчиков, посередине — ТТК каждого субподрядчика, есть возможность локализовать работы для бригад.

[СКРИН: экран распределения бригад и подрядчиков]

### Шаг 35. Распределение объёмов
В столбце справа — доступные субподрядчики, чьи бригады можно назначить на объект. Если нужного подрядчика нет — назначаем на генподрядчика.

[СКРИН: список субподрядчиков]

### Шаг 36. Распределение бригад и подрядчиков
В области посередине появляются ТТК из ранее созданного списка — выбрав любую, можно добавить бригады. По умолчанию назначается одна бригада, чтобы добавить ещё — выбрать ТТК и нажать «+» в верхней левой части секции. Для бригады задаётся количество человек и время выполнения (трудозатраты по СтроПро делённые на производительность за смену).

[СКРИН: карточка бригады с количеством людей и временем]

### Шаг 37. Завершаем СтроПро
Сохраняемся и идём далее.

[СКРИН: кнопка сохранения]

## slug: work-schedule-planning
title: Планирование графика работ
category: module
goal: Ознакомление с функционалом модуля «Планирование графика работ» — построение графика с учётом связей между работами.

### Шаг 5. Главное меню, переход к планированию графика
Выбираем «Планирование графика работ».

[СКРИН: пункт меню «Планирование графика работ»]

### Шаг 39. Экран планирования
Выбираем график из выпадающего списка и нажимаем «Показать график».

[СКРИН: выпадающий список графиков]

### Шаг 40. График
Открывается график назначенных работ: слева — список ТТК, правее — временные отрезки на календаре. Раскрывая списки, можно посмотреть работы по каждой блок-секции.

[СКРИН: график с временными отрезками]

### Шаг 41. Редактирование связей
Для правильной расстановки временных отрезков нужно расставить связи между работами — перейдите в режим редактирования связей кнопкой вверху списка.

[СКРИН: кнопка режима редактирования связей]

### Шаг 39b. Начало создания графика
В режиме редактирования связей открывается список всех ТТК объекта. Чтобы начать составление графика, дважды нажмите на нужную ТТК и отметьте чекбокс — все последующие ТТК будут выстраиваться от неё. Для совместных работ перетащите их в область ниже.

[СКРИН: выбор первой работы графика]

### Шаг 39c. Дальнейшее редактирование связей
Двойным нажатием выберите ТТК из списка — в столбце посередине появится порядок работ: в верхнюю половину перетаскиваем предшествующую работу, в нижнюю — совместную (выделяется зелёным).

[СКРИН: настройка порядка работ]

### Шаг 42. Редактирование временных отрезков
После редактирования связей ТТК представлены на графике временными отрезками. По умолчанию задано время выполнения, но можно задать вручную: клик по ТТК левой кнопкой → «Задать вручную».

[СКРИН: пункт «Задать вручную»]

### Шаг 43. Редактирование связей — завершение
После завершения работы с графиком нажимаем «Утверждено ДС» и «Утверждено ДЗ».

[СКРИН: кнопки утверждения графика]

### Шаг 44. Экспорт в Excel
Для экспорта графика в Excel нажмите соответствующую кнопку.

[СКРИН: кнопка экспорта в Excel]
